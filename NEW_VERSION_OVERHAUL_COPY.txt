### Layout
Two-column layout (40/60 split), code-aesthetic design

### Content

**Left Column:**

**Header (H2):**
```
The Engineering
```

**Subheader:**
```
Why this is interesting

```

**Body:**
```
LEVA is a real-time optimization problem:

Given a learner's current skill topology,
what's the next symbol that maximizes
expected global latency reduction?

It's not a simple "drill your weakest thing"
algorithm—that would be demotivating and
ignore transfer learning effects.

Instead, it's a weighted sampling problem
with multiple competing objectives:
- Minimize latency variance across domain
- Prevent recency bias
- Introduce musical structure
- Maintain flow state
- Model forgetting curves

The solution is an 8-feature probability
distribution that's recalculated after
every single tap.
```

**Right Column:**

**Code Block (Syntax Highlighted):**
```javascript
// Simplified probability calculation
function calculateProbability(voicing, state) {
  let p = BASE_PROBABILITY;
  
  // Latency weight (core feature)
  p *= (state.latency[voicing] / state.avgLatency) ** 2;
  
  // Recency penalty
  if (state.recentlyPlayed.includes(voicing)) {
    p *= 0.01; // essentially kill it
  }
  
  // Circle of fifths adjacency
  if (isAdjacentInCOF(voicing, state.lastVoicing)) {
    p *= 1.3;
  }
  
  // Success rate smoothing (flow state)
  if (state.sessionSuccessRate < 0.5) {
    p *= (1 - state.latency[voicing] / MAX_LATENCY);
  }
  
  // Forgetting curve
  const daysSinceLastSeen = getDaysSince(voicing);
  p *= Math.exp(daysSinceLastSeen / FORGETTING_HALFLIFE);
  
  return p;
}
```

```
Every session generates data about how jazz pianists actually learn.

```

**Three Insight Cards:**

**Card 1:**
**Headline:** The 80/20 Rule Holds
**Body:**
```
Early data suggests ~20% of voicings account for 80% of practice time.
These aren't necessarily the "hardest" voicings—they're the ones with
the highest confusion adjacency (voicings that sound/look similar).

Implication: The skill tree should cluster confusable voicings together
to force disambiguation.
```
**Visual:** Bar chart showing practice time distribution

**Card 2:**
**Headline:** Transfer Learning is Real
**Body:**
```
Mastering drop-2 major 7 voicings appears to accelerate drop-3 major 7
learning by ~30%. This suggests voicing families share motor patterns.

Implication: The skill tree unlocking sequence matters—some voicings
are "gateway skills" that unlock entire regions of the space.
```
**Visual:** Network graph showing voicing relationships

**Card 3:**
**Headline:** Session Length Sweet Spot
**Body:**
```
Preliminary data shows latency improvement peaks around 25-30 minutes,
then plateaus or regresses. This aligns with research on motor learning
fatigue thresholds.

Implication: The app should suggest breaks after 30 minutes, not
encourage marathon sessions.
```
**Visual:** Line graph showing latency improvement over session duration
